## Dependency security

The audit identified Prisma 6.12 as an unaffected compatible version. Both Prisma CLI and client were pinned to 6.12.0, the lockfile was regenerated by npm, and `npm ls` confirmed the affected `effect` and `deepmerge-ts` chain is absent. Schema/client generation and migration generation succeeded with Prisma 6.12.0.

An online `npm audit` run on 7 September 2026 reported zero known vulnerabilities across 270 installed dependencies. Re-run it before deployment and assess any new findings. A successful build or a clean advisory scan is not a security certification.

## Operational limitations to accept or address

- LAN connectivity is required to deliver new answers. Internet connectivity is not required for local operation.
- Redis is a cache; acknowledged answers and all grading state are durable in PostgreSQL.
- Browser fullscreen/blur handling is monitoring assistance, not OS-level lockdown.
- Cloud delivery is one-way, at least once, with an idempotent event ledger. It is not a full database backup or a two-way cloud school system.
- One central API server and one attempt per student/exam are supported. The documentation lists dashboard result limits and intentionally excluded school-management workflows.
- Default HTTP configuration is for initial isolated setup. Configure trusted HTTPS, strong credentials and backups for operational use.

The archive includes a SHA-256 source manifest. The packaging script reads every ZIP entry back and compares its bytes to the source, and verifies the presence of dotfiles, the lockfile and the initial migration while excluding installed dependencies, `.env` and build output.
